# Service_app

Service_app backend using [Python 3.12](https://docs.python.org/3.12/), [FastAPI](https://fastapi.tiangolo.com/), [Postgres 16](https://www.postgresql.org/docs/16/index.html), [OpenAPI](https://spec.openapis.org/oas/v3.1.0.html), [sqlc](https://sqlc.dev/), and [Atlas](https://atlasgo.io/). Local runtime uses [Docker](https://docs.docker.com/engine/install/). Cloud runtime in [Azure](https://azure.microsoft.com/en-gb/explore/) tbd.
